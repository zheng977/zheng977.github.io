StepGuard: Learning Step-Level Guardrails for LLM Agents

A lightweight guard that checks candidate tool actions before execution and audits complete agent trajectories.

Method

From contrastive trajectories to a calibrated guard

Motivation

Unsafe actions should be stopped before they happen

Tool-using agents can modify files, disclose information, and perform external actions. A guard that examines only the completed trajectory may identify the problem after an irreversible action has already occurred.

StepGuard moves the safety decision to the point immediately before execution. It evaluates the current interaction context together with the proposed action, then returns a structured safety judgment.

Overview

Abstract

LLM-based agents can interact with external environments through tool invocation, but this capability also introduces risks such as file modification, information leakage, and unauthorized actions. We propose StepGuard, a 4B guard for both pre-action safety checks and trajectory auditing. StepGuard is trained with StepGen, which generates step-annotated safe and unsafe trajectory groups, and Balance-GRPO, which balances learning between safe and unsafe actions using feedback from the current policy. Across static safety benchmarks and guarded-agent environments, StepGuard provides strong safety judgments while preserving useful agent behavior.
